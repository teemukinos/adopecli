# Animate minimum with precise editable motion

The maintained `craft/runtime/tools/animate_acceptance.py` fixture exercises all
five public Animate operations and all eight export formats through the sealed
macOS package. A two-scene motion study combines live text, an interpolated shape,
a stable second scene and an independently authored embedded PCM cue. This is a
bounded native animation contract, not general interactive-player qualification.

## Occurrence-specific revisions and restoration

The 640 × 360 movie contains two 24-frame scenes at 24 fps. Independent PNG
measurements establish the first rectangle's linear positions and the exact scene
boundary. All twenty-four frames of the held second scene have identical pixels.
Reused object identity remains distinct from an occurrence selector: the initial
rectangle pose can move and change fill without changing its final stored pose.
The first title remains live text and receives a precise replacement.

An independent complete-state prediction admits only requested transform/paint
changes and the explicitly derived text outline and box metrics. Requested paint
values must have identical binary32 bits, even when the native JSON writer uses
a shorter decimal spelling. The initial fixture's double-precision JSON comparison
was corrected for only those requested paint values; every unrequested field still
compares exactly. Native glyph and layout checks qualify derived text fields.

Every rendered frame in the untargeted scene remains unchanged. Portable transfer
into independent private state reverses the edits, restores the complete expanded
native meaning and reproduces every one of the original 48 frame pixels. Original
source bytes and creation recipes remain exact throughout. Path-table compaction
is handled explicitly; restored serialized JSON is not claimed byte-identical.

## Native formats, sound and independent decoding

PNG sequences, GIF, sprite sheets, WAV, SVG, Lottie, HTML and MP4 all run through
public durable exports. Each repeats after a cold native save. The GIF retains
48 frames and a two-second accumulated duration with explicit centisecond timing.
Every sprite rectangle and padding interval is checked; separate half-size PNG
exports match all atlas cell pixels, and all padding pixels remain transparent.
SVG remains static, Lottie records the exact stage and held-frame range, and the
HTML title is escaped within a self-contained maintained player. The player is
not executed by this fixture; browser fidelity remains open.

An exact original one-second 440 Hz PCM cue is embedded in a separately imported
native document. WAV16, WAV24 and float WAV32 exports have 96,000 stereo sample
frames at 48 kHz: the cue followed by one second of silence. An independent oracle
checks every channel sample, with explicit integer quantization tolerances.
Original embedded audio bytes remain unchanged.

The native Video dependency encodes H.264/AAC MP4. Portable re-encoding reproduces
the original encoded movie exactly. A separate local FFmpeg reader checks both
original and revised actual MP4 files, their stream metadata, every decoded video
frame against native PNGs, AAC signal correlation and the silent tail. Matte
composition is explicit. H.264/AAC losses and possible decoded codec padding are
recorded separately from the exact logical two-second endpoint. This external
reader does not become a runtime dependency or a browser-playback claim.
