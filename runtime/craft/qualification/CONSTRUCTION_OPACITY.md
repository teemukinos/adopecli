# Native construction static opacity

The native observer binds each unanimated construction opacity to the actual
material socket and its animation data. Ordinary materials retain their initial
constant key; image/glow/masked gains can be unkeyed. A constant-opacity property
must not acquire a different value, nonconstant key handles, modifiers or an
unsupported driver/NLA override. Declared animated opacity keeps its existing
keyframe checks. This does not qualify every shader connection or native property.

`craft/runtime/tools/construction_opacity_acceptance.py` exercises public verify
and render operations on the complete retained campaign. The original control
must keep every full-size RGBA pixel, native object/camera record and declared
asset/font byte unchanged. Private native-only variants change the first
headline opacity either immediately or at frame 48 while preserving its declared
constant opacity. Both inner and outer file receipts are correctly rebound.
Both operations must refuse each variant without publishing or changing its
imported project head. Six native attempts and three imports remain distinct.

The fixture uses an independently authenticated package-verification record and
an exact baseline PNG hash. Resume observes existing durable jobs and starts
only an unattempted queued job; failed or live work is not silently retried.
Recorded native groups must be absent after completion. Negative sources are
private qualification evidence, not release artwork. This local unit does not
establish publisher signing, stock-host, reboot, Linux/Cloud, billing or owner
creative acceptance.
