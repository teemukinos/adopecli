# A dope CLI operation inventory

Generated by `python3 -B craft/capability_inventory.py`. Run with `--check` to reject stale inventory.

Current source registers **97 local operations** across **17 native application families** and three additional production profiles. Hosted admission explicitly allows **86 operations**, including portable project import.

These are source contracts, not installed availability or release qualification. Query the actual package for availability. Never infer Linux, Supabase, clean-machine or visual acceptance from registration.

Inputs, revision preconditions and bounds are defined by each linked parameter validator and contract. Deliverables depend on the selected operation and profile; an inspection operation need not render every listed format.
